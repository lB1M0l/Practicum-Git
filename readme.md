# 📐 Пифагоровы тройки

Проект для поиска и проверки наборов из трёх целых чисел (a, b, c), удовлетворяющих условию: **a² + b² = c²**.

---

### 📖 Описание
Пифагорова тройка состоит из длин сторон прямоугольного треугольника. Самый известный пример — **3, 4, 5**.

### 🚀 Инструкция по запуску
Программа упакована в JAR-файл для удобного запуска.

**Команда для запуска:**
```bash
java -jar library.jar
